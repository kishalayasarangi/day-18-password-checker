# Day 18 — Password Strength Checker

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A password strength checker with live feedback,
strength meter and password generator.

## How to view
Open `index.html` in your browser.

## Features
- Live password strength meter
- Checks length, uppercase, numbers, symbols
- Password visibility toggle
- Random strong password generator
- Copy to clipboard
